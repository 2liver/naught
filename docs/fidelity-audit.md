# 拟真对齐清单(诚实版)

边界先声明(不可漂移的宪章):naught 是**纯画面拟真**——只复刻屏幕现象,不做机器拟真(不跑 BASIC、无 PETSCII 图形字符、无键盘矩阵/蜂鸣/时序)。本清单在"屏幕现象"边界内,按 对齐/近似/风格化/缺失 四档诚实记账。

## 逐机盘点

### 0 琥珀(Osborne Executive)
| 项目 | 档位 | 说明 |
|---|---|---|
| 网格 | ✅ 对齐 | 80 列(Cmd+0 原生网格) |
| 行数 | ⚠️ 缺失 | 真机 24 行;我们随窗口高度 |
| 屏幕形状 | ⚠️ 缺失 | 真机 5 英寸 4:3 小屏;我们随窗口 |
| 磷光色 | ✅ 对齐 | P3 琥珀系,调研校准 |
| 余晖 | ◐ 近似 | 双指数方向对;时标偏长(风格化拖尾) |
| 字形 | ◐ 近似 | Fusion Pixel 替身;非 Osborne 字符 ROM |
| 扫描时序 | ✳ 风格化 | 真机 60Hz 不可见;我们 3s 慢带 |

### 2 C64(彩色监视器)
| 项目 | 档位 | 说明 |

## 可以进一步对齐的清单(按代价排序)
1. **固定行数 + 屏幕形状**:四机锁定真实行数(24/16/25)与 4:3 画幅——代价:窗口比例约束,或用黑边补足。
2. **C64 阴罩点状三色组**:竖条 → 六角点阵(真 1702 结构)。
3. **字形 ROM 复刻**:Osborne/5100/C64/IBM 字符 ROM 的字形逐点复刻——许可问题(Apple II 即因此归档);C64 的 PETSCII 字符集有社区复刻(CC0/自绘)。
4. **余晖时标校准**:双指数常数对齐 P1/P3/P4/P22 的实测衰减曲线。
5. **曲率加大**:5 英寸管的真实球面曲率(需配合不裁字的内缩)。
6. **扫描时序真实化选项**:60Hz 真实场扫描 + 相机模式(当前 0.7s 慢放保留为"教学镜头",另设真实档)。

## 结论
**对齐**:分辨率、四机配色、16 色盘、束斑/聚焦物理、栅/衍射方向。
**近似(替身)**:四机字形、余晖时标、栅结构。
**风格化(刻意)**:慢放扫描、拖尾余晖、弱曲率、暖机、反光/边框、追随视角。
**缺失(边界外)**:机器行为、屏幕形状/固定行数。

一句话:屏幕现象的"路子"全部踩在物理方向上,量级上有意风格化;字形是许可约束下的替身;机器行为本就不在宪章内。
