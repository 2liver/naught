## 四、构建与发布（速查；细节见 `docs/构建发布.md`）

- 依赖：Qt 6.9.3（macOS 6.9.3/macos）+ KF6 SyntaxHighlighting（可选，缺失则「编」退化为等宽+行号）+ CMake ≥3.16
- 构建：`cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build --parallel`
- 自检：`build/naught.app/Contents/MacOS/naught --selftest`（三模式矩阵：默认 / `NAUGHT_RHI_SKIP=metal,vulkan` 无 GPU / `NAUGHT_CI=1` CI 冒烟）
- 部署：`scripts/deploy-stable.sh` → `~/Applications/naught.app`；打包 `scripts/package.sh 0.3.x`
- 发布：推 `v*` 标签 → `release.yml` 三平台构建 + GitHub Release 四资产
