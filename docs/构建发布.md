## 1. 依赖

| 依赖 | 版本/路径 | 说明 |
|---|---|---|
| Qt | 6.9.3（macOS 用 `~/Qt/6.9.3/macos`；Windows msvc2022_64；Linux 由 CI 安装） | qmake/cmake 均可；用 CMake |
| KF6 SyntaxHighlighting | `~/kf6`（libKF6SyntaxHighlighting.6.31.0.dylib） | **可选**：缺失则「编」（⌘B）退化为等宽+行号（`NAUGHT_WITH_HIGHLIGHT` 未定义） |
| CMake | ≥3.16 | |
| Xcode CLT / MSVC / gcc | 随平台 | macOS 部署目标钉 12.0 |

## 2. 构建

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
# ASAN 复验（发布前）：
cmake -S . -B build-asan -DCMAKE_BUILD_TYPE=RelWithDebInfo -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer"
cmake --build build-asan --parallel
```

## 3. 自检矩阵（发布门禁，全绿才可发布）

```bash
# 1) 默认（真 GPU 全量，含像素调校闸）
build/naught.app/Contents/MacOS/naught --selftest

# 2) 无 GPU 降级（Null 后端，GPU 闸豁免）
env NAUGHT_RHI_SKIP=metal,vulkan build/naught.app/Contents/MacOS/naught --selftest

# 3) CI 冒烟（NAUGHT_CI=1：跳过像素调校闸，逻辑闸全跑）
env NAUGHT_CI=1 NAUGHT_RHI_SKIP=metal,vulkan build/naught.app/Contents/MacOS/naught --selftest

# 4) 文本配方探针（选区逐键落点 T1–T4 + 四场景回归闸）
env NAUGHT_TEXT=1 build/naught.app/Contents/MacOS/naught --selftest
```

关键环境变量：`NAUGHT_RHI_SKIP`（后端跳过表）、`NAUGHT_REQUIRE_GPU=1`（退回 Null 即 FAIL，CI 硬闸）、`NAUGHT_TRACE=1`（按键/选区/冻结取证落盘，发布版默认关）。

## 5. 发布（GitHub）

1. 改 `CMakeLists.txt` 版本号；更新 `CHANGELOG.md`、`docs/roadmap.md`（M 行）。
2. 合并 preview → main（合并树必须精确等于 preview 树——历史上自动合并拼坏过着色器）。
3. 本地跑完 §3 全矩阵 + ASAN。
4. 打标签并推送：`git tag -a vX.Y.Z -m "..." && git push origin main preview vX.Y.Z`。
5. `release.yml` 自动三平台构建 + GitHub Release 四资产（macOS DMG/zip、Windows zip、Linux AppImage）。**Windows zip 的 KF6 由 CI 从源码构建**——手工打包必须补 `KF6SyntaxHighlighting.dll`，否则「编」丢语法高亮。
6. Windows 运行期硬依赖 `d3dcompiler_47.dll`（windeployqt 会带；手工拼包勿漏）。

## 6. 已知防御性观察（暂无害，改动相关代码时注意）

1. `m_readbackGen` 在 `resetPipeline()` 里不自增——上一代迟到回读仍会落地一次（画一帧旧内容）。
2. 回读回调的 `QRhiReadbackResult*` 在"回调永不触发"时会泄漏（实测未触发）。
3. macOS 上 gles2 后端 create 会崩在 Qt 内部——候选表按平台限定（macOS 只有 Metal/Null），不要加回。
