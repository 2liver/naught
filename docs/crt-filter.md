# CRT / 显像管滤镜设计笔记（「显」）

状态：**未实现**，1.0 之后的味道工程。此笔记只锁讨论范围，不锁方案。

## 定位

- 只影响显示，不改内容；QPainter 逐层绘制（扫描线/掩膜/荧光点），无 shader、无 OpenGL。
- 挂在「编」视图之下，与阴/阳正交（阴=黑底绿磷，阳=米白底黑墨）。

## 必谈的光学现象（按优先级）

1. **扫描线（raster lines）**：隔行暗线，随行高与缩放重采样（字号变化时扫描线密度跟着变，否则会摩尔）。
2. **光栅衍射（raster diffraction）**：亮边缘经过孔径栅（aperture grille）/荫罩时产生的**彩色条纹与彩虹散斑**——CRT 最具辨识度的瑕疵，也是本滤镜的灵魂：
   - 黑白文字的高对比边缘 → 三色磷粉的横向衍射彩色边（红/绿/蓝条带）
   - 高亮块与暗背景交界 → 衍射晕（diffraction bloom）向外溢色
   - 实现方向：把文字渲染成高位深灰度图 → 按 RGB 磷粉三色光栅采样 → 对亮区做横向微偏移三通道重绘 + 低通溢散（三色略微错位合成）
3. **磷粉三色组（RGB phosphor triad）**：竖直栅条（Trinitron 风格）或三角点（shadow mask 风格）；每像素按 1/3 子像素取样，采样即天然衍射。
4. **余晖与闪烁（persistence & flicker）**：磷粉余晖让滚动带拖尾（低频 60Hz 闪烁用隔帧明暗模拟，仅作强度提示，不做真频闪）。
5. **球面与晕影（curvature & vignette）**：轻微枕形/桶形畸变 + 四角暗角，强度极低（无界面原则：不抢字）。
6. **辉光（bloom）**：亮区向邻域扩散的高斯低通，先于衍射叠加。

## 性能底线

- 大文档打字/滚动时滤镜开销必须保持 ≈ 0（只处理可见区域 + 只在高亮切换时整帧重算）。
- 帧内实现只用 QPainter：半透明扫描线覆盖 + 预先合成的磷粉掩膜图（一次生成，平铺）。
- 若做不到 O(可见区) 就砍掉衍射，保扫描线 + 晕影。

## 开关

- 命名候选：「显」（显像管）或「磷」（磷粉）；快捷键暂空，进菜单与「编」并列。
- 关闭 = 完全无残留（所有图层属于同一生命周期，随会话结束即无）。
