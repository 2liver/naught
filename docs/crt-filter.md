# CRT / 显像管滤镜设计笔记（「显」）

状态：**一期已实现并上线**（`Cmd/Ctrl+T` 开关，自检 + ASAN + 基准护航）；
二期（真衍射 / 磷粉激发 / 真高斯辉光）留待 1.0 之后。

## 目标

**跨时空通讯感**：一键把「無」变成 1982 年 Osborne Executive 那类老便携机的屏幕——
你在这头码字，屏幕那头是过去时代的机器。写科幻时，显示器就是那台时间机器。

## 铁律（2026 定稿）

1. **零 UI**：没有选项、没有对话框、没有预设切换器。菜单里只有一个开关「显」
   （「编」之下，快捷键候选 `Cmd/Ctrl+T`），开了就是过去，关了就是现在。
   禅意优先：质感全部来自画面本身，不来自任何可调的东西。
2. **单一模式**：只有一个样子——**琥珀磷光**（P3，Osborne Executive 1982 的
   招牌色，也是便携写作机的鼻祖，与無同构）。磷色以命名常量存在，想换只改一处。
3. **纯画面拟真**：只模拟人眼隔着玻璃看显像管的质感。**无声音**。
4. **不损害写字**：打字清晰度与延迟优先于一切效果；任何效果超预算就砍。

## 单一配方（按画面层次，从底到顶）

1. **磷光排版**：嵌入中文像素字体——**缝合怪像素 Fusion Pixel**（已核：OFL-1.1，
   泛中日韩覆盖，可捆绑，[TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font)，
   最新 2026.09.01）。取 **12px Monospaced TTF 轮廓版的中文片（zh_cn）**，
   整数像素字号 + 关抗锯齿渲染（像素字不模糊），视网膜 2× 锐利；随包附 OFL 许可文本。
   ASCII 由同字体覆盖（不另叠 VT323）。文本 + 行号 + 笔迹全部染成琥珀磷色
   （核心亮色 `#FFB000` + 暗晕色）。
2. **辉光（bloom）**：文字层 2~3 次加宽描边叠低透明度（一期）；真高斯用
   1/4 降采样往返（二期）。
3. **扫描线**：预渲染 1×3 明暗掩膜平铺，间距随字号自适应，防摩尔。
4. **余晖（persistence）**：上一帧内容层 15% 静态混入——打字/滚动留下短暂
   磷粉残影。二期加"新敲字符更亮"的磷粉激发（需计时器）。
5. **光栅衍射**：一期 = 文字两次 ±1px 低透明度补色重绘（亮边缘的彩边近似）；
   二期 = 灰度层 → RGB 三色栅采样 → 三通道微错位真衍射。
6. **噪声与灰尘**：两帧预生成噪声图 8~15Hz 交替（≈0 成本）。
7. **玻璃质感**：四角暗角 + 一道对角淡白反光带（一次性预渲染覆盖层），
   不做桶形畸变（毁打字）。
8. **入场暖机**：切进「显」时一次由暗到亮的磷粉预热脉冲。**无频闪**（ADHD 友好）。

## 架构与预算（一期实测）

- 模块 `crt.{h,cpp}`：`CrtBackdrop`（磷底 + 视口快照降采样辉光 + 余晖混入）+
  `CrtOverlay`（玻璃/扫描线烘一层 + 噪声 + 暖机）+ `Editor::toggleCrt()`；
  与「编」「阴/阳」正交可叠加。
- 实测（离屏软件光栅最坏值）：打字 0.22 ms/键（≤1.5 ✓）、缩放 0.27 ms/次、
  滚动 5.2 ms/步（≈5 ✓，真机 GPU 更优）；辉光 80ms 节流、滚动 <24px 惰性滞后。
- 辉光实现为一期方案的"快照降采样"变体（比描边近似更接近真辉光），
  真高斯留给二期。

## 二期参考（~/Projects/AsciiGameTemplate/shaders/crt.gdshader）

本机项目的 Godot CRT shader 验证了二期模型并给出参数起点（QPainter 路线不引用其代码，只引用效果栈与量级）：

- **色差/衍射**：R 通道采样 `uv+off`、B 通道 `uv-off`——三通道错位模型与我们的方案一致；起始量级 0.002（极小）。
- **孔径栅**：`sin(subpixel × 3 × TAU)` 逐子像素调制——即磷粉三色栅；对应 QPainter 的预渲染 3 列掩膜，强度 0.3。
- **扫描线** 0.25、**晕影** 0.35、**闪烁仅 4%**——印证"不做真频闪"的判断。
- 桶形畸变裁掉界外像素——我们不采纳（毁打字），但可借鉴"四角裁圆"的极弱版。

## 二期参考：数字化光栅衍射的物理模型（来自分享对话 967cbu35）

二期"真衍射"不是拍脑袋的滤镜，而是有严格物理对应的采样问题：磷粉三色栅
（R/G/B 子像素周期）就是一个 **N=3 的二元光栅**，亮边出彩边 = 光栅衍射的自然结果。

- 衍射场 = **单像素孔径包络 sinc(m/N) × 周期内编码结构因子 Σgₙe^(−i2πmn/N)**：
  三通道 ±off 错位采样实现的正是这个结构因子；sinc 包络解释为何高级次
  （离亮边更远的彩色条纹）迅速衰减——所以衍射彩边只需 1~2px 宽。
- 像素孔径效应：子像素不是理想点，高级次被 sinc² 压制 → 我们只需模拟
  ±1 像素的 R/B 错位，不必做更宽的光谱展开。
- 相位项（0/π 二元相位光栅把能量移到 ±1 级）对应"亮边两侧色相相反"的
  观察——红在一边、蓝在另一边，而不是同侧彩虹。

## 分期

- 一期（已上线）：字体 + 琥珀磷色 + 扫描线 + 辉光（降采样近似）+ 余晖 + 噪声 + 玻璃 + 暖机。
