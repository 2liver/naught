# CRT / 显像管滤镜设计笔记（「显」）

状态：**未实现**，1.0 之后的味道工程。此笔记锁目标与范围，不锁细节方案。

## 目标（2026 补充）

**跨时空通讯感**：一键把「無」变成 1982 年 Osborne Executive / 1975 年 IBM 5100
那样的老终端——你在这头码字，屏幕那头是过去时代的机器在应答。写科幻时，
显示器就是那台时间机器。

气质关键词：绿磷/琥珀磷光的呼吸、玻璃管深处的余晖、打字时磷粉被重新点燃、
隔着一块厚玻璃与过去的自己对话。**无界面原则不变**：不做假 UI（假 CP/M 状态栏、
假启动画面都不要），质感来自 字体+磷光+玻璃+噪声 本身。

## 预设（三台机器，三种磷粉）

| 预设 | 参照 | 磷粉 | 气质 |
|---|---|---|---|
| 绿磷 | IBM 5100 (1975) | P1 绿 `#4AF626` 核 / 暗绿晕 | 方字、重扫描线、强余晖、轻微噪声——时间机器 |
| 琥珀 | Osborne Executive (1982) | P3 琥珀 `#FFB000` 核 / 橙晕 | 字稍软、扫描线轻、晕影重——暖色便携机 |
| 纸白 | 80 年代末监视器 | P4 白 / 灰晕 | 效果最淡、可读性最高——与「阳」最近 |

默认：**琥珀**（Osborne 是"便携写作"的原型机，与無的定位最像）。
切换入口：菜单栏/右键菜单「编」之下，快捷键候选 `Cmd/Ctrl+T`（T=Tube/Time）。
与「编」正交可叠加（在绿磷管上写代码）；与阴/阳正交（阴=黑底磷光，阳=米白纸磷）。

## 技术栈映射（纯 Qt 6 / QPainter，无 shader、无 OpenGL）

优先级从高到低（每项都满足"可见区预算"）：

1. **字体（灵魂）**：嵌一套可商用的中文像素字体（候选：缝合怪像素 Fusion Pixel、
   方舟像素 Ark Pixel、Zpix；ASCII 用 VT323 / IBM 3270 风格；**OFL 优先，捆绑前核许可**）。
   渲染要点：整数倍字号（12/24px）、关闭抗锯齿与微调（QFont::NoAntialias）、
   视网膜屏按 2× 渲染保证像素锐利。复用 `activeFont()` 机制（编模式的换字体轮子已有）。
2. **磷粉配色**：预设 = 一对颜色（核心亮色 + 暗晕色），QPalette 全量替换；
   笔迹（涂/擦）跟随磷色——在磷光屏上作画是加分项。
3. **扫描线**：预渲染 1×3 明暗掩膜 QImage 平铺覆盖（drawImage 一次），
   间距随字号/缩放自适应（像素字体 12px 时约 3px 一周期），防摩尔。
4. **辉光（bloom）**：文字层预渲染成 QImage 后降采样再平滑放大（1/4 尺寸往返 = 廉价高斯），
   只在该层脏时重算；或 2~3 次加宽描边叠低透明度（更省，先做这个）。
5. **余晖（persistence）**：缓存上一帧内容层，新帧 85% + 旧帧 15% 静态混合——
   滚动与打字留下短暂绿色残影；"新敲字符更亮"的磷粉激发需要计时器，放到二期。
6. **光栅衍射**（一期可砍）：内容层灰度图 → 按 RGB 磷粉三色栅采样 → 三通道
   横向 ±1px 微错位合成，亮边缘出红绿蓝彩边；近似版 = 两次 ±1px 低透明度
   补色重绘（便宜 10 倍，先做近似）。
7. **噪声与灰尘**：预生成 1~2 帧静态噪声 QImage 平铺（5~8% 透明度），
   8~15Hz 低频交替（成本 ≈ 0）——"这台机器活着"的关键。
8. **玻璃与晕影**：不做真桶形畸变（会毁打字清晰度）；用四角径向渐变暗角 +
   一道对角淡白反光带（一次性预渲染覆盖层）。
9. **不做真闪烁**：60Hz 频闪对眼睛（尤其 ADHD）不友好——余晖 + 噪声已够"活"。
   只保留一次入场"开机闪"：切进「显」时一瞬由暗到亮的磷粉暖机脉冲（一次性）。

## 架构

- 新模块 `crt.h`：`CrtOverlay` 覆盖层（同 Canvas 的层级套路）+ `CrtPreset` 结构
  （磷色对、扫描线间距、噪声、辉光强度）+ `Editor::toggleCrt()`。
- 管线（每次重绘）：内容快照（缓存，contentsChanged/滚动/缩放时失效）→
  衍射/辉光 → 扫描线 → 噪声 → 晕影。
- 只处理可见区域；滚动时快照层平移复用，不重合成。
- `--bench` 增加 CRT 行（打字/滚动/缩放带滤镜的开销）；预算：多行打字 ≤ 1.5ms/键、
  滚动 ≤ 5ms/步，超了就砍衍射/降辉光。

## 分期

- **一期**：字体 + 磷粉三预设 + 扫描线 + 辉光（描边近似）+ 余晖 + 噪声 + 晕影。
- **二期**：光栅衍射（三通道错位）+ 磷粉激发（新字符亮起）+ 暖机/关机脉冲动画。
- 每期独立可关；关闭 = 零残留（所有图层同生命周期）。
